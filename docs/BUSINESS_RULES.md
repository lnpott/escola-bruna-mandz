# Regras de Negócio

## Objetivo

Este documento descreve as regras de negócio conhecidas do sistema Escola Bruna Mandz.

Este arquivo representa o funcionamento definido do sistema.

Quando uma regra ainda não estiver definida, ela deve permanecer como "A definir" até que uma decisão seja tomada.

---

# Visão Geral

O sistema tem como objetivo administrar uma escola de música através de um painel administrativo.

Os módulos principais são:

- Alunos
- Professores
- Agenda
- Financeiro
- Loja

---

# Painel Administrativo

Todo o sistema será utilizado inicialmente através de um painel administrativo.

O painel será responsável por concentrar:

- Cadastros;
- Controle das atividades;
- Visualização de informações;
- Gerenciamento financeiro;
- Gerenciamento da loja.
